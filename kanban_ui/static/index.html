New project
Lowercase latin, digits, hyphen. 2 to 32 characters.
Optional. Path to the Claude Code project on disk.

Kanban creates an empty PLAN.md in the directory (for a one-time import of a plan you write before connecting) and adds an instruction block to CLAUDE.md. After that, agents file new tasks with kanban_create — editing the file later does not change the board.

First specify the project directory (field above).
Selected: 0

Tick the files to import tasks from. Files like PLAN/BACKLOG/TASKS are checked automatically. The parser reads ## Backlog, ## In progress, ## Done headings and the like — every - [ ] ... line becomes a card. The import runs once; CLAUDE.md then tells agents to file new tasks with kanban_create.

The URL is stored in the project DB; the token goes to kanban_data/.env-secrets with mode 600 as KANBAN_GIT_TOKEN_<ID>. Issue import will arrive in the next release.
